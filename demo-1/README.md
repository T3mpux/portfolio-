# Demo 1 Landing Page: GrowthPilot Coaching

Landing page demo for a freelance AI-assisted web development portfolio.

## Tech

- Next.js
- React
- Tailwind CSS
- Local component state for the lead form
- No backend

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
```

## Deploy to Vercel

1. Push this repository to GitHub.
2. Import the repository in Vercel.
3. Set the Root Directory to `demo-1`.
4. Keep the default Next.js build settings.
5. Deploy.
