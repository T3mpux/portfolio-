# Portfolio

Freelance AI-assisted web development portfolio demos.

## Demo 1 Landing Page: GrowthPilot Coaching

A modern Next.js and Tailwind CSS landing page for a fictional online business coach.

Project folder: `demo-1`

```bash
cd demo-1
npm install
npm run dev
```

Open `http://localhost:3000`.

For Vercel, import this GitHub repository and set the project root directory to `demo-1`.
